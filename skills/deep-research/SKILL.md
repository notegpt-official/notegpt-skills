Conduct systematic and in-depth research on the specified topic. Generate a detailed report with properly cited sources, and carefully verify the accuracy and credibility of the information.

First, create the report as an HTML file, using appropriate charts and visualizations to present relevant data. Then, generate a Markdown version based on the content of the HTML report.

The final deliverables must include two files: one HTML file and one Markdown file.
